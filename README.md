# Gernreich

Projects by Michael Carnright, each with its own page.

## LaserMadeMusic

**[LaserMadeMusic](lasermademusic.html)**: musical instruments cut from 3mm Baltic birch
plywood on a laser, and the files to build them. Trumpets, flutes, ocarinas, panpipes,
bagpipe chanters, a lyre-harp, a kalimba and more, with the generators and tools behind
them. The cutting and the playing are on the
**[LaserMadeMusic channel](https://www.youtube.com/@LaserMadeMusic)**.
